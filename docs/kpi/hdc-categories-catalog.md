## 2. แคตตาล็อกรายหมวด

สัญลักษณ์ความเป็นไปได้: **ได้** = ข้อมูลปีงบ 2569 มีครบ (HDC ≥ 18 จาก 21 หน่วย) / **บางส่วน** = มีแต่ไม่ครบหน่วยหรือต้องสมมติฐาน / **ไม่ได้** = ไม่มีข้อมูลในแหล่งนั้น
Effort: S = ใช้ pattern เดิมได้เกือบทั้งหมด (≤ 1 วัน), M = SQL ใหม่ + ตรวจนิยาม (2–3 วัน), L = ต้องตีความ/รวมหลายแฟ้ม/มีปัญหาข้อมูล (≥ 1 สัปดาห์)
ปีงบ 2570 ของ HDC ยังว่างทุกตัว ข้อสรุป "ได้" ใน HDC จึงหมายถึง**แฟ้มมีโครงสร้างและมีข้อมูลปี 69 ครบ** คาดว่าปี 70 จะเติมตาม
