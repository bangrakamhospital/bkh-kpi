# ค่าส่งยาที่บ้าน (`/delivery`)

แท็บหลัก "ค่าส่งยาที่บ้าน" รายงานการส่งยาที่บ้านทางไปรษณีย์และ Health Rider กับการคิดค่าส่ง **ทุกสิทธิ** ตามปีงบประมาณ (1 ต.ค.–30 ก.ย.) จาก HOSxP เท่านั้น ข้อมูลสรุปเท่านั้น ไม่มีข้อมูลระดับบุคคล ต้องเข้าสู่ระบบ (บัญชี `approved`) เหมือน `/pp`

แยกจากรายการ `DRUG_DELIVERY_POST` / `DRUG_DELIVERY_RIDER` ในหน้า `/pp/other` (รายได้ สปสช. นับเฉพาะ UC, `NHSO_DRUG_DELIVERY_SQL`) ซึ่งไม่เปลี่ยน

## แหล่งข้อมูลและรหัส (ตรวจด้วย db-cli 17 พ.ย. 2569)

- `nondrugitems` ที่ชื่อมี ส่งยา / ไปรษณีย์ / จัดส่ง / ขนส่ง / rider / ไรเดอร์ / delivery มีค่าส่งยาเพียง 2 รายการ ทั้งคู่ราคา 50 บาท income `16` ADP `DRUGP`
  - `3002455` ค่าจัดส่งยาทางไปรษณีย์
  - `3002725` ค่าจัดส่งยาโดย Health Rider
- ทุกสิทธิคิดด้วย icode เดียวกันในราคา 50 บาท **ไม่มีรายการแยกสำหรับผู้ป่วยจ่ายเอง** (ราคา ADP DRUGP ใน master: UCS 50, OFC/LGO/SSS 0 คือเบิกจากกองทุนเหล่านั้นไม่ได้ แต่ HOSxP ยังคิด 50 บาทจากผู้ป่วย)
- `prscrpt_delivery` (1 แถว/vn) = บันทึกการจัดส่งของห้องยา เลขพัสดุ `prscrpt_delivery_track` (PB…TH / PC…TH หรือ NULL)
- Health Rider ไม่มีที่บันทึกการส่ง (`health_rider_register` ว่าง) เห็นได้จากการคิดเงินเท่านั้น
- `opitemrece.paidst` บอกผู้จ่าย: `02` ลูกหนี้สิทธิ (เรียกเก็บกองทุนของสิทธิ), `01` ชำระเองเบิกได้, `03` ชำระเองเบิกไม่ได้ (`00` ค้างชำระ, `04` ส่วนลด — ปีงบฯ 2569 ไม่มีในรายการค่าส่ง)

### สิทธิจ่ายเอง (CSH)

ไม่พบการคิดค่าส่งของสิทธิที่ `pttype.hipdata_code = 'CSH'` เลย ทั้งปีงบฯ 2569 และย้อนหลังตั้งแต่ปี 2563 และไม่มี visit สิทธิ CSH ใน `prscrpt_delivery` (ตรวจทั้ง `ovst.pttype` และทุกแถวของ `visit_pttype`) "ผู้ป่วยจ่ายเอง 50 บาท" ที่เกิดขึ้นจริงในข้อมูล คือรายการค่าส่งของสิทธิอื่นที่ลง `paidst` 01/03 (ข้าราชการ, อปท., ประกันสังคมส่วนหนึ่ง) จึงแสดงเป็นคอลัมน์ "ผู้ป่วยชำระเอง (บาท)" ของแต่ละกลุ่มสิทธิ แถว "จ่ายเอง (ชำระเงิน)" ยังคงแสดงเป็น 0 เพื่อให้เห็นว่าไม่มีข้อมูล

## นิยาม (ต่อ เดือนของ `ovst.vstdate` × กลุ่มสิทธิ)

| ตัวเลข | นิยาม |
|---|---|
| ส่งไปรษณีย์ | visit ในปีงบฯ ที่มีแถว `prscrpt_delivery` และเลขพัสดุไม่ NULL / ว่าง / `-` (บันทึกไม่มีเลขอาจยกเลิกการส่ง: ไม่นับ) |
| คิดค่าส่งแล้ว | visit ที่ส่งไปรษณีย์และถูกคิด `3002455` หรือ `3002725` นับ 1 ครั้งต่อ visit (กติกาเดียวกับ `/pp/other`) |
| ยังไม่คิด | ส่งไปรษณีย์ − คิดค่าส่งแล้ว, บาท = visit × 50 (ประมาณ) |
| คิดค่าส่งไปรษณีย์ | visit ทั้งหมดที่ถูกคิด `3002455` (รวม visit ที่ไม่มีบันทึกส่ง/ไม่มีเลขพัสดุ) และ `SUM(opitemrece.sum_price)` |
| Health Rider | visit ที่ถูกคิด `3002725` และ `SUM(sum_price)` |
| เรียกเก็บกองทุน / ผู้ป่วยชำระเอง | ยอดบาทของทั้งสองรายการแยกตาม `paidst` 02 / 01+03 |

**กลุ่มสิทธิ** = `pttype.hipdata_code` ของสิทธิที่รายการค่าส่งถูกเรียกเก็บ (`opitemrece.pttype`, `MIN()` ถ้า visit มีหลายสิทธิ) และของ `ovst.pttype` เมื่อ visit ยังไม่ถูกคิดค่าส่ง เหตุผล: visit หนึ่งมีได้หลายสิทธิ (`visit_pttype`) สิทธิที่ใช้คิดรายการคือผู้รับภาระค่าส่งจริง ปีงบฯ 2569 ทุกรายการค่าส่งมี `opitemrece.pttype = ovst.pttype` ตัวเลขจึงเท่ากันทั้งสองแบบ การจัดกลุ่มใช้ `PTTYPE_GROUPS` (overview.ts): UC = UCS, ประกันสังคม = SSS+SSI, ข้าราชการ = OFC, อปท. = LGO, จ่ายเอง = CSH, อื่นๆ = ที่เหลือ (NRD/NRH, INS, BKK/BMT/SRT/PTY/PVT/STP/A2, ไม่ระบุ)

Plan: CTE ทุกตัวมีช่วงวันที่ เริ่มจาก `ovst` by `vstdate`, `pttype` join ท้ายสุดไม่มีเงื่อนไข เวลาคิวรี FY2569 ≈ 2.3–2.5 วินาที

## ข้อสังเกตและข้อจำกัด

- **Health Rider = 0 ตั้งแต่ ก.ค. 2569** (ต.ค. 2568–มิ.ย. 2569 เดือนละ 83–237 visit) แล้วกลับมามีการคิดในปีงบฯ 2570 (ล่าสุด 17 พ.ย. 2569) ควรตรวจกับ PCU ว่าหยุดส่งหรือไม่ได้คิดเงินช่วงนั้น หน้าเว็บแสดงเดือนที่เป็น 0 เป็นสีส้ม
- UC ส่งแล้วยังไม่คิดค่าส่ง 801 visit ≈ 40,050 บาท ที่เบิก สปสช. ได้ (รายละเอียดใน ppfs-revenue-feasibility.md 10.7)
- ประกันสังคมส่ง 87 visit คิดค่าส่งเพียง 3 (+ Rider 4) ควรยืนยันนโยบายว่าเก็บค่าส่งจากผู้ประกันตนหรือไม่ ส่วนข้าราชการ/อปท. คิดเกือบครบและเก็บจากผู้ป่วย (`paidst` 03)
- "คิดแล้ว" คือมีรายการคิดเงินใน HOSxP ไม่ใช่ยอดที่รับชำระจริงหรือยอดโอนจาก สปสช.
- Rider ไม่มีบันทึกการส่ง จึงไม่เห็นเคสที่ส่งด้วยไรเดอร์แต่ไม่ได้คิดเงิน
- ตัวเลขปีงบฯ ที่ยังไม่สิ้นสุดเป็นยอดสะสมถึงวันที่ดึงข้อมูล
