# PP / รายได้คัดกรอง (PPFS): ศึกษาความเป็นไปได้

> สถานะ: feasibility study (db-cli, HOSxP `--conn 1` เท่านั้น, 2026-11-12) **และ Phase 1 ทำแล้วในแท็บ `/pp`** ดูข้อ 10
> ขอบเขต: แท็บฝั่งโรงพยาบาล (HOSxP) ไม่ใช้ HDC และไม่มีข้อมูลระดับอำเภอ
> อัตราจ่าย: PPFS ปีงบฯ 2569 ตาม https://www.uckkpho.com/ppfs69/ เพราะอัตรารายรายการของปีงบฯ 2570 ยังไม่ประกาศ
> (อัตราในเอกสารนี้เป็นตัวเลขที่ผู้สั่งงานให้มา ยังไม่ได้เปิดหน้าเว็บตรวจซ้ำ ดูข้อ 8)
> ทุกตัวเลขเป็น**ยอดรวม** ไม่มีข้อมูลระบุตัวบุคคล

## 3. นิยามรายรายการและผล FY2569

ทุกรายการที่ไม่ได้ระบุไว้ใช้ประชากรตามข้อ 1 (ในเขต + ไทย)

### 3.1 FPG 40 ฿ (อายุ 35–59 กลุ่มเสี่ยง ปีละครั้ง ไม่รวม DM)
- ประชากร 35–59 ปีที่ไม่เป็น DM = 3,311 คน
- **target** = คนที่มีผลคัดกรอง NCD ใน FY2568–2569 แล้วเข้าเกณฑ์เสี่ยง (`dm_risk_count > 0` หรือ BMI ≥ 25 หรือ BP ≥ 130/85) = **1,058** คน (proxy ของ "กลุ่มเสี่ยง")
- **earned** = target ที่มี lab FBS (`76`/`817`) ที่มีผลใน FY = **611** คน (ทุกคนในกลุ่ม 35–59 ที่ไม่เป็น DM และมี FBS = 1,092 คน, ที่ถูกคิด `12003` = 355 คนในเขต)
- หมายเหตุ: คัดกรอง NCD ครอบคลุม 3,287 คน แต่เป็น DTX (`last_fgc`) เกือบทั้งหมด (`last_fpg > 0` = 0) ซึ่งไม่เข้าเงื่อนไข FPG venous

### 3.2 TC + HDL 160 ฿ (45–70 ปี ทุก 5 ปี ไม่รวม dyslipidemia/statin)
- ประชากร 45–70 = 4,543 คน → ตัดคนที่มี E78 หรือเคยได้ statin ก่อน FY เหลือ 2,691 คน → ตัดคนที่เคยตรวจ TC/HDL ในช่วง 2020-10-01 ถึง 2025-09-30 เหลือ **target 1,651** คน
- **earned** = target ที่ตรวจทั้ง TC (`102`) และ HDL (`91`) ใน FY = **169** คน
- ถ้าไม่ใช้เงื่อนไข 5 ปี จะมีคนตรวจใน FY 769 คน ส่วนรายการ `12004` ถูกคิดกับคนในเขต 396 คน (51 คนในนั้นเป็น E78 หรือได้ statin) จึงน่าจะมีส่วนที่ถูกปฏิเสธหรือเสี่ยงถูกปฏิเสธ
- ป้าย ADP ใน HOSxP เขียน 45–59 ปี แต่เกณฑ์ที่ผู้สั่งงานให้มาคือ 45–70 ปี ต้องยืนยันกับประกาศ PPFS 2569

### 3.3 มะเร็งปากมดลูก (หญิง 30–59 ปี 5 ปีครั้ง)
- หญิง 30–59 = 2,211 คน → ตัดคนที่เคยคัดกรองใน 5 ปี (SPECIALPP ข้อ 2.2 หรือ lab `1017`/`474` ในช่วง 2020-10-01 ถึง 2025-09-30) เหลือ **target 1,182** คน
- **earned** = target ที่คัดกรองใน FY = **218** คน (HPV ทั้งหมด ไม่มี Pap/VIA อย่างเดียว) ถ้าไม่ใช้รอบ 5 ปีจะเป็น 292 คน
- อัตราที่ใช้คือเก็บตัวอย่าง 50 + HPV 2 genotype 280 = **330 ฿/คน** แต่ HPV อยู่กลุ่ม EXTERNAL LAB ถ้าแล็บภายนอกเป็นผู้เบิกค่าตรวจ รพ. จะได้แค่ 50 ฿ (earned เหลือ 10,900 ฿) ยังไม่ทราบว่าใช้ชุดตรวจ 2 หรือ 14 สายพันธุ์
- รายการ `C30` (เก็บตัวอย่าง 50) ไม่เคยถูกคิด แต่ `1B004` (Pap/VIA 250) ถูกคิด 266 คนในเขตในวันตรวจ HPV จึงอาจคิดผิดรายการ (ดูข้อ 7)
- Colposcopy 900: ไม่มีบริการหรือการคิดเงินใน FY2569 (เกรด C)

### 3.4 FIT 60 ฿ (50–70 ปี ทุก 2 ปี)
- ประชากร 50–70 ที่ไม่มี C18–C20 = 3,742 → ตัดคนที่มี FIT ใน FY2568 เหลือ **target 3,698** (ใน FY2568 แทบไม่มี FIT)
- **earned** = **269** คน (lab `978` 267 คน, SPECIALPP 1B0060/1 264 คน ซึ่งซ้อนกันเกือบทั้งหมด) และถูกคิด `90005` 261 คน
- lab และ SPECIALPP ตรงกัน จึงเป็นรายการที่ข้อมูลสะอาดที่สุด

### 3.5 HBsAg 50 ฿ / Anti-HCV 50 ฿ (เกิดก่อน พ.ศ. 2535 ครั้งเดียวในชีวิต)
- เกิดก่อน 1992-01-01 = 7,147 คน
- HBsAg: ตัดคนที่เคยตรวจ (lab `122` หรือ SPECIALPP 1B010*) ก่อน FY และคนที่เป็น HBV อยู่แล้ว เหลือ **target 4,701** คน **earned 486** คน (ตรวจใน FY ทั้งหมด 635 คน)
- Anti-HCV: ตัดคนที่เคยตรวจ (lab `219`/`430`/`1081` หรือ 1B011*) และคนที่เป็น HCV อยู่แล้ว เหลือ **target 5,048** คน **earned 529** คน (ตรวจทั้งหมด 623 คน)
- ไม่มี ADP PP ใน `nondrugitems` ส่วน lab ถูกคิดเป็นค่า lab ปกติ (ADP type 15) จึงยังไม่เห็นว่าเบิกแบบ PP หรือไม่

### 3.6 โลหิตจาง
- **CBC 65 ฿** หญิง 13–24 ปีที่ไม่ตั้งครรภ์ ปีละครั้ง: ประชากร 511 คน ตั้งครรภ์ (`person_anc` ที่ครรภ์คาบเกี่ยว FY) 8 คน จึงได้ **target 503** คน, **earned 79** คน (Hb ในฟอร์ม Hematology) และถูกคิด `13001` 46 คน
- **Hb/Hct 30 ฿** เด็ก 6–12 เดือน: ใช้ cohort ที่อายุครบ 6 เดือนใน FY (เกิด 2025-04-01 ถึง 2026-03-31) ได้ **target 43** คน, **earned 39** คน (lab `3`/`4`/`744`)
  - รพ. คิด `13001` (CBC 65) กับเด็กกลุ่มนี้ 40 คน ต้องยืนยันว่าเด็กควรเบิก 13001 หรือรายการ Hb/Hct 30
- **Hb/Hct 30 ฿** เด็ก 3–5 ปี: ใช้ cohort ที่อายุครบ 3 ปีใน FY (ตรวจหนึ่งครั้งในช่วงอายุ) ได้ **target 46** คน, **earned 8** คน
- Hct แบบ point-of-care ในคลินิกเด็กดีอาจไม่ได้ลง lab จึงทำให้ earned ต่ำกว่าจริงได้

### 3.7 ANC / หลังคลอด (service-based, หญิงไทยที่มีบริการ ANC ที่ รพ. ใน FY และมี LMP) = 289 ครรภ์
- **ANC 360 ฿/ครั้ง**: target = ครั้งตามตาราง 8 ครั้ง (GA 12, 20, 26, 30, 34, 36, 38, 40 สัปดาห์ จาก LMP) ที่ตกใน FY = **1,665** ครั้ง, earned = ครั้งที่บันทึก `person_anc_service` (นับวันไม่ซ้ำ) = **1,086** ครั้ง (ถูกคิด `30011` 1,203 ครั้ง)
- **Lab set 1 600 ฿**: target = ครรภ์ที่เข้าไตรมาส 1 หรือเริ่มฝากใน FY = **203**, earned = มี `LAB ANC` ใน FY = **188** (ถูกคิด `30012` 142)
- **Lab set 2 190 ฿**: target = ครรภ์ที่ GA 32 สัปดาห์ตกใน FY = **211**, earned = ใช้รายการที่ถูกคิด `30013` = **109** (ไม่มี lab marker แยก set 2 และ `blood_check2_date` ว่าง)

## 5. เกณฑ์เกรด
- **A**: ทั้ง target และ numerator มาจากข้อมูลที่บันทึกตรงตามเงื่อนไข ได้แก่ FIT
- **B**: ต้องใช้ proxy อย่างน้อยหนึ่งข้อ เช่น "กลุ่มเสี่ยง" ของ FPG, ประวัติตลอดชีวิตของ HBsAg/HCV, "CBC" = Hb, ตารางนัด ANC จาก LMP, หรือใช้รายการคิดเงินแทนบันทึกบริการ (lab set 2, ขัดฟัน, PNC)

## 7. ข้อสังเกตด้านคุณภาพการบันทึก (โอกาสเพิ่มรายได้ที่ไม่ต้องคัดกรองเพิ่ม)
1. HPV: มีการคิด `1B004` (Pap/VIA 250) แทน `C30` (เก็บตัวอย่าง 50) + ค่า HPV ควรตรวจว่าเบิกถูกรายการหรือไม่
2. TC+HDL: คิด `12004` ให้คนที่มี E78/statin 51 คน และหลายคนเคยตรวจภายใน 5 ปี ซึ่งเสี่ยงถูกปฏิเสธ
3. HBsAg/HCV: ตรวจ 486–529 คน (เข้าเงื่อนไขครั้งแรกในชีวิต) แต่ไม่มีรายการ PP ให้คิด จึงน่าจะยังไม่ได้เบิก PP
4. FPG: คัดกรอง NCD ใช้ DTX เกือบทั้งหมด ถ้ากลุ่มเสี่ยง (1,058 คน) ได้เจาะ FPG venous ครบ จะเพิ่มได้ราว 18k ฿
5. ANC: `blood_check1/2_date`, `post_labor_service*_date` ว่างทั้งหมด ถ้าบันทึกจะเลิกพึ่งรายการคิดเงินได้ ส่วน TSH ทารกไม่ได้บันทึกเลย

## 9. สิ่งที่ยังไม่แน่ใจ / ยังไม่ได้ตรวจ

- ทุกค่าที่เปลี่ยนตามปี bind เป็น named parameter รายการรหัสเป็นค่าคงที่ใน source และตรวจด้วย `sqlCodeList` / `sqlIntList`
- พารามิเตอร์: `:periodStart` = 1 ต.ค., `:countFrom` = `:periodStart`, `:dataAsOf` = 30 ก.ย. ของปีงบฯ, `:lookbackFrom` = ต้นช่วงย้อนหลังของรอบสิทธิ (กำหนดต่อรายการ)
- **billed** = จำนวน visit (distinct `vn`) ของคนในเป้าหมาย ที่มี `opitemrece.icode` ซึ่ง `nondrugitems.nhso_adp_code` ตรงกับรายการ ในปีงบฯ เป็นชั้น "บันทึกแล้ว เทียบกับ คิดเงินแล้ว" ไม่ใช่สถานะการเบิกจริง ถ้ารายการไม่มีรหัส ADP ที่ รพ. ใช้ จะเป็น `null` (HBsAg, Anti-HCV)
- ตาราง/dialog แสดงหน่วยตาม `unit` (คน / ครั้ง / ครรภ์) และป้าย `population` (ประชากรในเขต / ผู้มารับบริการที่ รพ.) กับป้าย "เพดาน" (`ceiling`)
- Dialog รายหมู่บ้าน (`PpfsVillageButton`) ใช้ `<dialog>` แบบเดียวกับ `VillageDetailButton` แต่ข้อมูลมากับหน้าแล้ว (ยอดรวมรายหมู่ ไม่มี request เพิ่ม ไม่มีรายชื่อ ไม่ต้อง login)

### 10.3 ความต่างจากผลศึกษา (ข้อ 3–4)
- **TC + HDL**: จำกัดการย้อนดู statin เป็น 5 ปี (เดิมดูทั้งประวัติ) target จึงเป็น 1,655 (เดิม 1,651)
- **ANC ต่อครั้ง**: done = 984 ครั้ง (จำกัด 8 ครั้งต่อครรภ์) ข้อ 3.7 ใช้ 1,086 ซึ่งไม่จำกัด ถ้าจำกัดด้วยจำนวนนัดที่ตกในปีงบฯ จะได้ 900 การนับนี้ยังไม่หักครั้งที่มาก่อน 1 ต.ค. ออกจากเพดาน 8 ครั้ง
- **ANC ครั้งที่ 9+ (ตัดสินใจโดยผู้ใช้ อ้างเงื่อนไข สปสช.)**: ครั้งที่ 1–8 ต่อครรภ์ จ่าย 360 ฿ โดยไม่ต้องส่งเอกสารเพิ่ม ครั้งที่ 9 ขึ้นไปเบิกได้เมื่อจำเป็นทางการแพทย์ แต่หน่วยบริการต้องส่งหลักฐานให้ สปสช. พิจารณา
  - earned (`done_visits`) = ครั้งที่ 1–8 เหมือนเดิม
  - เพิ่มคอลัมน์ `extra_visits` = Σ max(ครั้งในปีงบฯ − 8, 0) และ `extra_pregnancies` = จำนวนครรภ์ที่มีครั้งที่ 9+ แอปแสดงเป็น `PpfsItem.potential` ("ครั้งที่ 9+ (ต้องส่งหลักฐาน)") ใต้แถว ANC ในช่องทำแล้ว/ได้แล้ว และกล่องหมายเหตุในชื่อรายการ **ไม่รวม** ใน earned, target, gap และยอดรวมบนการ์ด เพราะเป็นรายได้ที่อาจได้ ไม่ใช่รายได้ที่แน่นอน
  - target ยังสอดคล้องกับกฎนี้: target นับนัดตามตาราง 8 จุด (GA 12–40 สัปดาห์) จุดละไม่เกิน 1 ครั้ง จึงไม่เกิน 8 ครั้งต่อครรภ์ และไม่รวมครั้งที่ 9+
  - FY2569 (db-cli): 289 ครรภ์, ครั้งในปีงบฯ ทั้งหมด 1,086 = ครั้งที่ 1–8 **984** (354,240 ฿) + ครั้งที่ 9+ **102** ครั้ง จาก 33 ครรภ์ (สูงสุด 17 ครั้งต่อครรภ์) ≈ **36,720 ฿**
  - ข้อจำกัด: ลำดับครั้งนับเฉพาะในปีงบฯ ครรภ์ที่มาก่อน 1 ต.ค. จึงอาจมีครั้งที่ 9+ จริงมากกว่านี้ (และ earned 1–8 สูงไป) เท่ากับจำนวนครั้งที่มาก่อน 1 ต.ค.
- อายุ TC + HDL ยังใช้ 45–70 ปี โดยมี caveat ว่าป้าย `12004` ใน HOSxP เขียน 45–59 ปี

### 10.5 Performance และ cache
- เวลา query (db-cli, FY2569): TC + HDL 7 วินาที (18 วินาทีตอน buffer เย็น, เดิมไม่จำกัด statin 24 วินาที), HBsAg 8–9, มะเร็งปากมดลูก 7, Anti-HCV 7, FIT 4, FPG 1.3, ANC 0.3, CBC 0.2 วินาที
- ส่วนที่หนักของ TC + HDL คือ statin: `ix_icode` ต้องอ่าน statin ทั้งประวัติ (~250k แถว) เพราะไม่มี index (icode, vstdate) ช่วงวันที่จึงลดได้ไม่มาก การบังคับ `ix_hn` ช้ากว่า (เกิน 60 วินาที)
- query รันขนานกันผ่าน pool 5 connection หน้า `/pp` ตอน cache ว่างใช้ประมาณ 12 วินาที และ 0.5 วินาทีเมื่อมี cache
- `"use cache"` ต่อปีงบฯ: ปีที่ยังไม่สิ้นสุดใช้ `cacheLife("hours")`, ปีที่ปิดแล้วใช้ `cacheLife("days")` (ไม่ใช้ `max` เพราะยังมีการบันทึกย้อนหลัง) ถ้ามีรายการใด query ล้มเหลวใช้ `"minutes"` และแสดงข้อความ error เฉพาะแถวนั้น invalidate ด้วย `revalidateTag("kpi:ppfs")`
