# คลินิกกายภาพ (`/clinic/pt`, กลุ่มเมนู "ประมาณการรายได้แยกคลินิก")

รายงานงานกายภาพบำบัดของโรงพยาบาล ทั้ง **ค่าบริการ/รายได้ตามสิทธิ** และ **ภาระงาน/ตัวชี้วัดติดตาม** ตามปีงบประมาณ (1 ต.ค.–30 ก.ย.) จาก HOSxP เท่านั้น (ไม่ใช้ HDC) ข้อมูลสรุปเท่านั้น ไม่มีข้อมูลระบุตัวผู้ป่วย โครงสร้างเดียวกับ `/clinic/ncd` (docs/kpi/ncd-clinic.md)

## ไฟล์

สิทธิ 2 กลุ่ม "เต็มจำนวน" / "เหมาจ่าย (hospmain = รพ.)" ใช้กติกาเดียวกับ NCD: import `NCD_SCHEME_RULES` / `NCD_SCHEME_INDEX` จาก `sql/ncd-clinic-hosxp.ts` แบบอ่านอย่างเดียว (ชื่อสิทธิ/กลุ่มคัดลอกมาใน `pt-clinic.ts` เพราะ NCD ไม่ export)

## นิยาม visit กายภาพ (ไม่ใช้ `ovst.main_dep` อย่างเดียว)

- งานกายภาพราว 30% บันทึกใน visit ที่ลงทะเบียนแผนกอื่น (NCD 062, OPD 061 ฯลฯ — นักกายภาพตรวจเท้า/สอนผู้ป่วย/ทำกายภาพหลังพบแพทย์) จึงนิยาม **visit กายภาพ** = แถว `ovst` ที่ `vstdate` ในปีงบฯ และ
  - มีแถว `physic_list` (รายการที่บันทึกผ่านโมดูลกายภาพ) อย่างน้อย 1 แถว ไม่ว่า main_dep ใด **หรือ**
  - `main_dep = 027` "กายภาพบำบัด" และมีรายการในทะเบียนกายภาพคิดใน `opitemrece` (กายอุปกรณ์/พันผ้ายืดที่คิดเงินโดยไม่มี `physic_list` ~137 visit, 0.54 ล้านบาท)
- visit ที่ลงทะเบียน 027 แต่ไม่มีรายการกายภาพเลย (257 visit FY2569) ไม่นับ
- **คน** = `ovst.hn` ไม่ซ้ำ การแยกตามเดือน/สิทธิ/กลุ่มโรคนับคนซ้ำข้ามกลุ่มได้
- ตาราง `physic_main` (โมดูลเดิม) หยุดใช้ตั้งแต่ ก.พ. 2568 ไม่นำมาใช้ โมดูลปัจจุบันคือ `physic_register` / `physic_plan` / `physic_plan_detail` / `physic_list`
- ผู้ป่วยใน: `physic_plan_detail` ที่มี `an` — แสดงแยกเป็นข้อมูลประกอบ ไม่รวมในยอด OPD (จ่ายตาม DRG)

## ค่าบริการ

- **ค่ากายภาพ** = `opitemrece.sum_price` ของ icode ที่อยู่ในทะเบียน `physic_items` (กลุ่ม 1 กายภาพบำบัด = income 14 + 3002052 ค่าตรวจเท้า income 12, กลุ่ม 3 กายอุปกรณ์ = income 02) บน visit กายภาพ = ค่าที่ HOSxP คิด ไม่ใช่รายรับจริง ใช้ `IN (SELECT icode FROM physic_items)` เพราะ `physic_items` มี icode ซ้ำ (JOIN ทำให้ยอดเกิน 0.2 ล้าน)
  - ตรวจไขว้: ยอดเฉพาะแถว `opitemrece` ที่ผูกกับ `physic_list.opi_guid` = 13.37 ล้าน; นิยามตามทะเบียน = 13.95 ล้าน (ต่าง = 137 visit ข้างต้น + รายการทะเบียนที่คิดโดยไม่ผ่าน physic_list)
  - ไม่ใช้ income 14 ทั้งหมด เพราะ income 14 รวมจิตบำบัด/ให้คำปรึกษาของคลินิกจิตเวช (020/019) และคลินิกตา (018) ด้วย
- **ค่าอื่นของ visit** = `vn_stat.income` − ค่ากายภาพ เป็นข้อมูลประกอบเท่านั้น: รวมยา/lab ของคลินิกอื่นใน vn เดียวกัน **ซ้อนกับ `/clinic/ncd`** ห้ามนำไปรวมยอดคลินิก
- กลุ่มเหมาจ่ายได้รับเงินรายหัว ยอดที่คิดไม่ใช่รายรับ (กองทุนฟื้นฟูฯ/IMC ของ สปสช. จ่ายบางรายการเพิ่ม — ไม่ได้แยกในรายงานนี้)

## ตัวชี้วัด / ส่วนของหน้า

| ส่วน | นิยาม |
|---|---|
| ผู้รับบริการ / visit | ตามนิยามข้างต้น แยก visit ลงทะเบียน 027 กับ visit แผนกอื่น |
| รายใหม่ | คนที่ไม่มี visit กายภาพ (`physic_list`) ใน 365 วันก่อน 1 ต.ค. |
| ผู้สูงอายุ | `vn_stat.age_y` ≥ 60 ใน visit กายภาพใด ๆ |
| กลุ่มโรค | ICD-10 ใน `ovstdiag` ทุก diagtype ของ visit กายภาพ: stroke I60–I69, ระบบประสาท G00–G99, กระดูกกล้ามเนื้อ M00–M99, บาดเจ็บ S00–T98, อื่นๆ = ไม่มี 4 กลุ่มนี้ (ส่วนใหญ่ visit NCD ที่ dx เป็น DM/HT) |
| จำนวนครั้ง/คน | 1, 2–5, 6–10, >10 visit ในปีงบฯ |
| รายการบริการ | ต่อ icode: หน่วย (`opitemrece.qty`), visit, คน, บาท แสดง 15 อันดับ Excel ทั้งหมด |
| ภาระงาน | วันให้บริการ = วันที่มี visit กายภาพ; visit/วัน; นักกายภาพ = `physic_list.doctor` (doctor_position 9 "เจ้าหน้าที่กายภาพ"); visit ต่อนักกายภาพ-วัน = คู่ (vn, นักกายภาพ) ÷ (วัน × นักกายภาพ) |
| มาตามนัด | `oapp.depcode = '027'`, `nextdate` ในปีงบฯ, kept = `visit_vn` ไม่ว่าง (ตัวชี้วัด หน่วย "ครั้ง") |
| เวลารอคอย | เฉพาะ visit main_dep 027: `ovst.vsttime` → `MIN(physic_list.begin_datetime)` 0–480 นาที ไม่รวมวันนี้ (median = MariaDB `MEDIAN`, p90 = `PERCENTILE_CONT(0.9)`) ไม่วัด visit แผนกอื่น (ทำกายภาพหลังคลินิกอื่น เฉลี่ย ~3 ชม.) |
| IMC ได้รับกายภาพ | admission จำหน่ายในปีงบฯ (`an_stat.dchdate`) `ipt.dchtype = '01'` (With Approval) pdx: stroke I60–I64, TBI S06.1–S06.9 (ตัด S06.0 สมองกระทบกระเทือน ~75 ราย/ปี ไม่ใช่ IMC), SCI S14.0–1/S24.0–1/S34.0–1, สะโพกหัก S72.0–S72.2; ได้รับ = มี `physic_plan_detail.an` หรือ visit กายภาพ OPD ภายใน 180 วันหลังจำหน่าย ("ยังติดตามไม่ครบ" = จำหน่ายไม่ถึง 180 วัน) |
| stroke ได้รับกายภาพระหว่างนอน | admission stroke (I60–I64, dchtype 01) ที่มี `physic_plan_detail.an` |
| ต่อเนื่อง ≥ 2 ครั้ง | คนที่มี ≥ 2 visit กายภาพในปีงบฯ ÷ คนทั้งหมด |
| กายภาพผู้ป่วยใน | `physic_plan_detail` ที่มี an, `ser_date` ในปีงบฯ: admission, คน (`physic_plan.hn`), ครั้ง (an+วัน), รายการ, บาท (`physic_plan_detail_price` ≈ opitemrece ของ an 0.303 vs 0.308 ล้าน) |

ตัวชี้วัดทั้งหมด **ไม่มีเกณฑ์ทางการ** ที่ตรงกับนิยามจาก HOSxP จึงแสดงเพื่อติดตาม (target = null, ไม่มีผ่าน/ไม่ผ่าน)

## ที่ทำไม่ได้ / ตัดออก

- **ตัวชี้วัด IMC ทางการ** (ติดตามครบ 6 เดือน หรือ Barthel Index = 20) — ตาราง `physic_barthel_*` ไม่มีการบันทึก จึงใช้ proxy "ได้รับกายภาพภายใน 180 วัน"
- **เวลาทำกายภาพต่อครั้ง** — `physic_list.end_datetime` บันทึกพร้อม `begin_datetime` (มัธยฐาน ~1 นาที) ไม่สะท้อนเวลาจริง
- **เวลารอของ visit แผนกอื่น** — กายภาพทำหลังคลินิกอื่น ไม่ใช่คิวกายภาพ
- **นาทีมาตรฐานภาระงาน** (`physic_items_minute`) — มีค่าในทะเบียน แต่ยังไม่ได้ตรวจความถูกต้อง จึงไม่ใช้
- **อาชีวบำบัด** (physic_group 2) — ไม่มีรายการในทะเบียน
- **รายรับจริง/การเรียกเก็บ สปสช. (กองทุนฟื้นฟู)** — ไม่อยู่ในขอบเขต HOSxP ส่วนนี้
